Privacy Policy — yt-uploader

Last updated: 2026-09-18

What this is. yt-uploader is a personal, single-user tool built by Danial Panah. It uploads videos from his own computer to his own YouTube channel using the YouTube Data API.

Who uses it. Only Danial Panah. It is not offered to, installed by, or run on behalf of anyone else.

Data accessed. Through Google OAuth, the tool requests permission to upload videos and manage the YouTube channel that Danial selects. It accesses only that channel.

Data collected or stored. None beyond what is needed to run: the OAuth token Google issues is stored locally on Danial's computer and is never transmitted anywhere except to Google's APIs. No analytics, no tracking, no third-party services, no databases.

Data shared. Nothing is shared with any third party.

Data deletion. Revoking the app's access at https://myaccount.google.com/permissions invalidates the stored token. Deleting the local token file removes the last copy.
